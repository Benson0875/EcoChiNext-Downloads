# 測量依據與不能宣稱的事

版本 0.13.0-observe；協議 `eco-gng-dual-1`、校正 `adc-neutral-range-1`。以下區分文獻構念与本專案工程規則，不把別人的效度移植成 EcoChi 的診斷效度。

## 1. 果實／石頭：Go/No-Go 改作

Go/No-Go 研究分別觀察 Go 反應與 No-Go 抑制、漏按、誤按和反應時間。EcoChi 用自製形狀、掌機 TFT、實體 A 鍵改作，不是原研究的測驗重製。可參考 [De Pue 等原始研究](https://www.nature.com/articles/s43856-025-01239-1)、[刺激間隔對 Go/No-Go 表現的原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8048576/)。

本版工程參數：8 題練習（6 Go／2 No-Go）、30 題正式（24 Go／6 No-Go）；等待 600–1000 ms、作答窗 1000 ms。縮短版參數尚需 pilot，不是臨床標準；正式只有 6 題 No-Go，單一誤按即可大幅改變該類錯誤率。

| 指標 | 計算與解釋 |
| --- | --- |
| 正確率 | 有效 Go 命中加有效 No-Go 抑制，除以有效認知題數；另列無效及預期題數 |
| 漏按／誤按 | 有效 Go 無窗口內反應／有效 No-Go 有窗口內反應；不是疾病症狀判定 |
| RT 中位數／SD | 有效正確 Go 首次確認作答的軟體時間；SD 少於兩筆顯示缺值，不補零 |
| 品質 | 提前、持續按住、多次按、呈現／輪詢异常及中斷獨立記錄，不藏在總分中 |

100 ms 極短 RT 排除等规则是工程品質選擇，不是疾病門檻。時戳起點是畫面提交後，不是像素真正亮起；GPIO 掃描与去彈跳也不等於物理按下。必須經光學／可重複按鍵台架校準才談誤差；[微控制器反應時間裝置研究摘要](https://pubmed.ncbi.nlm.nih.gov/20160303/)不能證明本 ESP32 已達同等準確度。

## 2. 傾斜與雙任務

GY-61 常用 ADXL335 三軸類比加速度計，可感受重力與動態加速度，但不是陀螺儀。參考 [Analog Devices ADXL335 官方資料表](https://www.analog.com/media/en/technical-documentation/data-sheets/adxl335.pdf)。

本版量的是握持掌機、傾斜控制球的任務表現：中心 RMS 誤差与有效時間中的中央比例。ADC、球座標、實際 dt、校正與缺樣保存；取樣目標 25 Hz，不宣稱每筆等間隔或直接量到人體平衡。

只辨認、只平衡、雙任務使用匹配窗口與規則，分别比較認知與動作變化，優先報差值而非單一健康總分。条件次序有六排列機制，真正研究仍需老師分配及查核次序平衡。

[上肢認知—動作雙任務原始研究](https://www.nature.com/articles/s41598-019-46925-y)使用不同的穿戴感測器、動作與受試族群，只能支持探索雙任務的研究方向，不能將其疾病區分效果套用到手持傾斜遊戲。

ADC 範圍、校正穩定、雙向響應、覆蓋率等門檻是本專案工程檢查，不是人體正常範圍。通過校正不保證感測器接線無誤。按 A 本身可能擾動握持，需在研究中檢查。

## 3. 環境與重複測驗

AHT20 是環境溫濕度，不是腦溫；MQ-135 僅相對氣體趨勢，不是精準 CO₂、AQI 或健康判定。疲勞 0–4 是可略過的專案自評，不冒充標準化量表。這些是背景，不能單憑相關推論環境造成認知下降。

[手機認知任務重測研究](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2021.734947/full)顯示裝置任務需要自己的重測／變化估計；不能把別人的信度直接移植。手機本來就能做認知測驗，EcoChi 的差異是固定實體鍵、離線掌機、傾斜與環境同步記錄，不是「手機不能做到」。優勢需要對照試驗。

## 4. 目前證據等級

已有工程實作與主機回歸、Arduino 編譯及歷史開機驗證紀錄；**完整實體流程、端到端時序、健康成人信度／效度尚未驗證**。沒有常模、腦齡、疾病風險、健康總分或「正常／異常」判定。

教師需先確認倫理程序與知情同意，再做健康成人可行性 pilot、跨日重測、練習效應、条件順序平衡、比較工具与預先分析。分析以參與者而非每題作為獨立樣本，考慮睡眠、視力、教育、慣用手、疲勞及手部限制。健康成人測試也不能直接證明疾病篩檢能力。
