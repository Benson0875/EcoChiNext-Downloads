# 遊戲操作與第一章

## 開始

沒有有效存檔先取名。方向鍵選 A–Z、0–9，A 加字、B 刪字，選 DONE 按 A 確認；最多 8 字，不可空白。已有有效存檔直接進地圖。

方向短按走一格，地圖按住約 500 ms 後每 180 ms 連走，鬆手停止；取名與選單不連發。面向前方一格 NPC 或物件按 A 互動。上方 E 為體力、B 為羈絆、H 為飢餓（越高越餓）；營火可休息。

B 開 Profile、Backpack、Missions、Settings。Settings 有 Save Game、Date / Time、Sound、Web Hub、Pet Name、Power Off。調時左右選欄位、上下修改、A 確認、B 取消，需要 DS3231。

冒險中長按 B 約 850 ms 請求存檔並安全關機，看到保存成功再切電源；評測內 B 是立即退出，不是關機。沒有 SD 仍能遊玩，但斷電可能遺失進度。

## 溪谷修復：五個區域

| 地圖 | 目標 |
| --- | --- |
| BUD CAMP 芽谷營地 | 守望員接委託、園丁交換工具、記錄員介紹環境觀察、營火休息 |
| REED TRAIL 蘆葦步道 | 北側找齒輪、南側收藏寶箱、用枝剪清除東側藤蔓 |

| SPRING CORE 泉心 | 讀碑文、操作三個水輪、修復水渠、捷徑回村交付 |

## 推薦路線

1. 出生後往上找 W 守望員，按 A 接委託。
2. 往東到蘆葦步道，在北側寶箱找齒輪。
3. 回營地找 G 園丁，交換永久工具枝剪。
4. 剪開步道東側藤蔓，進泵房啟動開關。
5. 進石鎖室，推石到圓環；錯誤可重置，不會永久卡關。
6. 到泉心讀碑文，依序操作水輪。
7. 修復水渠後走蓝色捷徑回村，找橋旁守望員交付，顯示 CHAPTER COMPLETE。

<details><summary>解謎答案（需要時再展開）</summary>

石塊向右推四格，再從南側向上推兩格。水輪順序：M（月亮）→ S（太陽）→ L（葉子）。

</details>

三個支線寶箱在營地北側果園、步道南側、修復後泉心北側，各領一次。果園藤蔓需枝剪。觀察牌需要有效溫濕度才能留環境紀錄，但缺感測器不阻擋通關。還可補圖鑑、Eco Stamp 與原有六項養成任務。

本版是可通關的第一章原型，沒有第二章、Boss 或完整戰鬥系統。地圖及圖形自行實作，不含薩爾達 ROM 或原作素材。

## 出生即可玩的兩個評測

出生在 `(5,7)`，左走一格面向記錄員按 A；右走一格面向教練按 A。兩者不需主線解鎖，也不以分數懲罰寵物或限制通關。詳見 [評測與網頁操作](assessment-guide.md)。
