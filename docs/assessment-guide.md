# 評測遊戲與離線網頁

**此處顯示本次任務表現，不判定大腦健康。**

## 記錄員：果實／石頭

說明 → 匿名代碼與可略過疲勞自評 → 8 題練習 → 即時結果 → 有 SD 且練習保存成功後進 30 題正式 → 即時正式結果。

看到圓形帶葉果實按 A，看到多角形石頭不按，不能只靠顏色。每題要放開再按。練習與正式分開；B 隨時退出，中斷不計正式完成。

結果包括正確率、漏按、誤按、有效題數、正確 Go 反應時間中位數及樣本標準差（SD）、提前／按住／多次按／無效紀錄。RT 是「未校準的軟體反應時間」，不是精確光學／物理反應時間。

## 平衡教練：傾斜中心控制與雙任務

坐姿、前臂舒適支撐，不站立或走路。先中立握持，再依提示緩慢左右及前後傾斜、按 A 確認方向響應。校正失敗請 B 退出並檢查接線，不用假數值補結果。

三條件為只辨認、只平衡、兩者同時，次序依工作階段安排並記錄。每條件先練習，有 SD 才進正式；同時做時兩項同等重視，讓球留在中央並遵守果實／石頭規則。

每條件結束掌機立即顯示結果。左右切認知／動作／品質頁，A 接續，B 退出返回原位置。完整三正式條件後可看 ΔRT、Δ錯誤率、Δ中心 RMS 與 Δ中央停留比例。缺基線、感測異常或資料品質不足明示原因，不產生假的比較。

中心 RMS 是正規化遊戲座標的中心誤差，中央比例是有效取樣時間中球在中央區的比例；不是人體重心、站姿平衡、角度或臨床量表。

## 保存與背景

評測暫停養成消耗、遊戲時間及遭遇，關閉 AP；有效作答窗不寫阻塞 SD。先顯示結果再保存，在題間等非作答時段保存 checkpoint。

工作階段独立放 `/next/assessment/`，保存匿名碼、協議／校正／韌體版本、逐題、ADC、環境及品質；不修改遊戲 v5 存檔。

無 SD 可練習並看結果，明示未保存；無 RTC 日期缺失但保留相對時間。完成與保存成功分開。B 中斷或斷電只保留已写出的部分，不續算正式完成，也不能保證斷電零遺失。

溫濕度、MQ-135 暖機及相對氣體趨勢、疲勞自評只是背景；不改正式難度、不推論認知下降原因。不要輸入真實姓名；匿名碼也不代表資料不能被重新識別，研究資料需老師管理。

## 電腦／手機看報告

1. 退出評測回地圖，B → Settings → Web Hub。
2. 手動連上掌機畫面顯示的 `EcoChi-xxxx`，密碼 **ecochi26**。
3. Windows 顯示「沒有網際網路」是正常的；USB 接上不會自動加入 Wi-Fi。
4. 瀏覽器輸入 **http://192.168.4.1**（不是 https）。
5. 開「認知觀測」選本次 RAM 或 SD 工作階段，查看條件結果、品質、背景與逐題；下載單次／全部 CSV、列印報告。

原有網頁也提供環境曲線、養成、圖鑑、章節進度與存檔備份。沒有 SD 就沒有持久化的完整歷史。不同協議、校正或不可比較紀錄不直接混為健康趨勢。

連不上時，先確認 AP 畫面仍開啟、電腦確實選掌機 SSID、VPN／其他網路沒有搶路由；AP 會因無人或運作上限關閉，請手動重開。固定密碼僅適合受控離線原型使用，不要讓陌生人加入；CSV 下載到電腦後由你保管，不會自動上傳 GitHub。

本版真實 AP 連線、SD 斷電恢復、GY-61 及完整實體流程仍需測試，不能把模擬網頁測試當實機通過。
